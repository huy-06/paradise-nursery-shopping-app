# Paradise Nursery Shopping Application

An online plant shopping application built with React and Redux Toolkit for Paradise Nursery. 

## Features
- **Landing Page**: Welcome screen with company introduction and a "Get Started" button.
- **Product Listing**: Plants grouped into 3 distinct categories with at least 6 plants per category. Features include dynamic plant cards, thumbnails, prices, and an "Add to Cart" button that disables when clicked.
- **Shopping Cart**: Real-time cart calculation, quantity modification, item removal, checkout alert ("Coming Soon"), and total cost per item.
- **Navigation Bar**: Persistent header showing company branding, links, and a dynamic cart icon tracking total items.

## Technologies Used
- React (Vite / CRA)
- Redux Toolkit & React-Redux
- CSS3
